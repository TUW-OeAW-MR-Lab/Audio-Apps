This is a VBAP demo, created in Matlab (startSPATIALIZE.m), and played with pure-data (launch with _OPEN DEMO.bat).

This demo presents a spatial simulation of birds, rain and thunder.

- Sources: 53
  - Sources  1-11: birds
  - Sources 12-29: rain
  - Sources 30-53: thunder
  - Sources 54-71: rain
- Directions: defined in label track channel
