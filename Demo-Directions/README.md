This is a VBAP demo, created in Matlab (startSPATIALIZE.m), and played with pure-data (launch with _OPEN DEMO.bat).

This demo presents a spatial simulation of example directions.

- Sources: 6
- Directions: defined in label track channel

The single directions, each played with 3s signals of pink noise cover the following angles (azi, ele):
- 0,0: North (long wall, directing entrance with glass door)
- 90,0: West (short wall)
- 180,0: South (long wall, opposite entrance)
- 270,0 (short wall, directing LED wall)
- 45,45 (elevation up)
- 225,-45 (elevation down)
