# Intro Music
- This is a music piece as introduction to spatial audio.
- Requires Intro_v2_C.wav in /Media
- Original source: Sonible, modified to RME Mix 1 configuration.
- To be remotely controlled, set Reaper to: 
  - Control surface mode: OSC
	- Device name: MRLab
	- Pattern config: MRLab (copy MRLab.ReaperOSC to %appdata%\Reaper\OSC)
	- Device port: 9342, Device IP: localhost
	- Local listen port: 10009
